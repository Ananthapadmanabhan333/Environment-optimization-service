## ⚡ QUICK WINS (FREE, <5 MINUTES)

### 1. Monitor Positioning
- [ ] Eye level or 15-20° below horizontal
- [ ] 25-30 inches away (arm's length)
- [ ] Straight ahead (no angled neck)

### 2. Declutter
- [ ] Remove items not needed for current task
- [ ] Close browser tabs (reduces visual load)
- [ ] Files in drawers, not desk surface
- [ ] Target: <20% of desk visible

### 3. Temperature
- [ ] Thermostat to 69-70°F
- [ ] Check for drafts/heat sources
- [ ] Dress in layers

### 4. White Noise
- [ ] Enable brown noise app (mynoise.net)
- [ ] Target 40-50 dB volume
- [ ] Adjust if too quiet or too loud

### 5. Desk Lamp
- [ ] Reposition for 300-500 lux
- [ ] Eliminate harsh shadows
- [ ] Avoid glare on screen

- [ ] Chair cushion or lumbar support

### Biophilic ($20-50)
- [ ] 2-3 potted plants (pothos, snake plant)
- [ ] Nature artwork/prints
- [ ] Natural materials (wood desk)

## 🧠 WHY THESE FACTORS MATTER

### Lighting = Alertness & Mood
- Cool light suppresses melatonin → increases focus
- Natural light maintains circadian rhythm
- 72 hours without sunlight → 50% mood decrease

### Sound = Distraction & Stress
- Unpredictable noise activates threat response
- Optimal ambient noise masks distractions
- Each interruption costs 23 minutes recovery time

### Layout = Posture & Cognition  
- Poor ergonomics → pain → reduced focus
- Visual clutter → 30% less working memory
- Nature views → attention restoration

### Climate = Cognition & Comfort
- 72°F → 5-10% cognition loss per degree higher
- CO₂ >1200ppm → measurable IQ reduction
- Temperature fluctuation → stress response

### Biophilic = Stress & Creativity
- Plants → 37% cortisol reduction
- Nature views → 37% stress reduction
- Ceiling height → creative thinking boost

## 🚨 COMMON MISTAKES TO AVOID

❌ **Don't:** Try to optimize everything at once
✅ **Do:** Implement high-impact changes first

❌ **Don't:** Ignore seasonal light changes
✅ **Do:** Adjust lighting seasonally (summer ≠ winter)

❌ **Don't:** Use overhead lights only
✅ **Do:** Mix task + ambient lighting

❌ **Don't:** Sit in complete silence
✅ **Do:** Use 30-50dB ambient noise

❌ **Don't:** Monitor directly in front of window
✅ **Do:** Position perpendicular to reduce glare

❌ **Don't:** Assume one solution fits all tasks
✅ **Do:** Adjust environment per task type

❌ **Don't:** Measure once and forget
✅ **Do:** Track weekly for 4-8 weeks
